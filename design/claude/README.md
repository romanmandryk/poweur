# Poweur ID logo — "globe key" (Claude Design exploration)

A key whose handle is the same size as a globe, its outlined shaft entering a
hole in the globe's face. Monochromatic indigo with a subtle diagonal gradient.

Design canvas (all rounds, tone tweaks): https://claude.ai/artifact/LycyzYUHnXZdhWobPdgURL

| File | Use |
| --- | --- |
| `mark.svg` / `mark-on-dark.svg` | Square mark, transparent background (light / dark surfaces) |
| `mark-wide.svg` / `mark-wide-on-dark.svg` | Same mark, tight wide crop |
| `app-icon-dark.svg` / `app-icon-light.svg` | 1024 app icon tiles (heavier strokes) |
| `favicon.svg` | Simplified heavy-stroke mark for 16–32 px |
| `lockup-horizontal*.svg`, `lockup-stacked*.svg` | Mark + "Poweur ID" wordmark |
| `png/` | Rendered app icons (1024/512/180), favicons (32/16), marks (512) |
| `tones/{teal,graphite,ember}/` | The mark in the alternative tones |

Colours (indigo): gradient `#262B80` → `#5B6AF0` on light, `#8C97FF` → `#E0E4FF`
on dark; wordmark ink `#15172E`; dark ground `#0D0F24`.

The lockups set the wordmark as live text in [Sora](https://fonts.google.com/specimen/Sora)
(Regular, "ID" Light), loaded from Google Fonts with a Helvetica/Arial fallback.
Convert the text to outlines before using the lockups in print or native apps.
