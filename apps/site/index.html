Why an open ID

Email is from 1971. Phone numbers belong to your carrier. Your account belongs to them.

We keep patching the same three things — an address people can reach, a login apps can trust, and a place to share files — across a dozen incompatible accounts. Poweur is one identity that does all three, and you can take it with you.

vs. walled gardens

No landlord for your identity

Your ID is a DNS name plus keys you hold. No platform can suspend it, mine it, or hold your contacts and files hostage when you leave.

vs. email

Reachable, not just addressable

Email delivers text to a mailbox. A Poweur ID also verifies who sent it, shares folders, signs in to apps and speaks structured data that software understands.

vs. phone numbers

Private by design

Stop handing out a SIM-bound number that leaks your location, invites SIM-swap attacks and gets recycled to a stranger. Share a name instead.

Poweured apps · preview

An app is just a folder. Your data stays in yours.

Because every user already has an identity, an inbox and a drive, an app needs no backend of its own. It signs you in, asks for a scoped grant to /apps/<app>/, keeps state in your home or a shared group folder, and talks to other IDs with typed messages.

  • No servers to run, no database to secure, no user table to leak
  • Open data conventions: two apps from different vendors can share one file
  • Uninstall revokes the grant — the data stays with you
  • @poweur/client for browser, Node, Bun and Deno

Today you can build on sign-in, messaging and the encrypted drive; the app-folder conventions are rolling out.

SDK docs App-data conventions
agent.ts
import { PoweurClient, signerFor } from "@poweur/client";
import { FileKeyStore, FileSessionStore, nodeResolveOptions } from "@poweur/client/node";

// An agent with an ID of its own: messageable, accountable, revocable
const keys = await new FileKeyStore().load("myagent.poweur.net");
const { signer, decryptor } = signerFor(keys!);
const client = new PoweurClient({
  relayUrl: "https://poweur.net", signer, decryptor,
  sessionStore: new FileSessionStore(), resolve: nodeResolveOptions(),
});

// Signed, end-to-end encrypted, to any ID on any relay
await client.send("alice.poweur.net", "Your report is ready.");

// ...and read what comes back
const { messages } = await client.inboxAndAck();
for (const m of messages) console.log(m.sender, m.plaintext);
Agents

Agents get IDs too.

An agent with its own Poweur ID can be messaged, trusted, granted a single folder and fired with one click. Messages and shared folders become the neutral handoff layer between people and AI — whatever model or vendor runs it.

Accountable

Every agent ID names an operator. You see who acts on your data and revoke them instantly.

Scoped

Grant one folder, read-only or read-write, for an hour or forever — never your whole account.

Ready for your tools

Coding agents like Claude Code or Codex use the poweur CLI directly, with JSON output. MCP, n8n and LangChain plug in through the SDK.
