# poweur

The `poweur` command line, so `npx poweur …` works. It is an alias for
[`@poweur/client`](https://www.npmjs.com/package/@poweur/client): same code, same version.

```bash
npx poweur identity create alice.poweur.net --hosted
npx poweur send hello.poweur.net "ping"
```

Documentation: <https://www.poweur.org/docs/clients/cli-reference>. Source:
<https://github.com/romanmandryk/poweur>. Licensed under Apache-2.0.
